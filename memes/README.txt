Optional: real meme / GIF stickers for GenZ Mode.

The 10 meme stickers on the GenZ page are made from emoji and original captions.
To show a real image or GIF on a sticker, add a file here named:

  meme-1.gif ... meme-10.gif   (.png or .webp also work)

  1-3  = "Pick your player" section      4-6  = "Features for you" section
  7-10 = "Features built for parents" section

A file shows at the top of its sticker automatically. If a file is missing, the emoji sticker stays.
Only use images you have the rights to (your own, licensed, or from a source whose terms allow
use on a commercial site). Film stills and characters are usually copyrighted.
