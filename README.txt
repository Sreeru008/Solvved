SOULVVED LANDING PAGE (V6 - real 3D iPhone + GenZ Mode (condensed font, interactive letters, pinned scroll sections)

OPEN IT
  Double-click index.html. It works from your computer.
  For your live website, upload this whole folder to any web host
  (Netlify, Vercel, Cloudflare Pages, etc.) and keep the folder structure.

FOLDER
  index.html, styles.css, script.js ... the page
  logo-dark.png ........................ logo used in Dark Mode
  assets/phone3d.js .................... 3D viewer (Three.js bundled)
  assets/iphone.glb .................... the iPhone 3D model
  assets/iphone.glb.js ................. same model, for opening the page by double-click.
                                         You can DELETE this file on your live website.
  screens/ ............................. your app screenshots (see screens/README.txt)

APP SCREENSHOTS ON THE PHONE
  Add screens/screen-1.png, screen-2.png, screen-3.png (1170 x 2532 px).
  They appear on the phone automatically. When hosted online they show as-is.
  When opened by double-click, browsers block images inside 3D, so the
  placeholder screens show instead. Use your hosted site (or a local server) to preview them.

GENZ MODE MEME STICKERS
  The sticker memes are emoji + original captions. To use real GIFs/images, see memes/README.txt.

IF THE 3D PHONE CANNOT LOAD
  The page falls back to the earlier CSS phone, so nothing breaks.

MODEL NOTE
  The file is named "Apple iPhone 18 Pro Max - Burgundy". Check its licence
  before using it commercially.
