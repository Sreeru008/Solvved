Put your app screenshots in this folder to show them inside the phone.

  screen-1.png  ->  Discover (swipe cards)
  screen-2.png  ->  Shared shortlist
  screen-3.png  ->  Match and chat

Use the same name and PNG format. Best size: 1170 x 2532 px (iPhone portrait).
The page picks them up automatically. Until a file exists, a placeholder screen is shown.
